# Laboratorio 1: Diseñar una comunicación periódica y un prompt reutilizable

**Duración:** 17 min

## Descripción
Crearán un prompt maestro que indique objetivo, audiencia, periodo que debe cubrirse, fuentes, tono, secciones del boletín y reglas para señalar información no confirmada[cite: 3]. Generarán una primera edición a partir de un conjunto inicial de fuentes y revisarán si la respuesta conserva el formato, prioriza lo relevante y mantiene el estilo de comunicación[cite: 3]. Dejarán preparada la conversación y el prompt como base reutilizable para elaborar nuevas ediciones sin reconstruir el proceso desde cero[cite: 3].

## Pasos para ejecutar la práctica

1. **Creación del Prompt Maestro y primera edición:**
   * Abre Microsoft 365 Copilot Chat.
   * Copia, pega y envía el siguiente prompt maestro para definir la plantilla reutilizable del boletín:
     ```text
     Actúa como Director de Comunicaciones Corporativas.
     
     Crea la Edición 1 del "Boletín Semanal de Innovación y Estrategia" para la audiencia de Líderes y Equipos de Negocio.
     
     Estructura del boletín:
     1. Titular de la Semana
     2. Resumen Ejecutivo (máximo 3 líneas)
     3. Destacados Estratégicos (3 noticias o hitos con contexto e impacto)
     4. Alerta de Información no Confirmada (aspectos que requieren validación previa)
     
     Tono: Profesional, directo y consultivo.
     
     Contenido base inicial: Genera los hitos de esta primera edición abordando el lanzamiento de nuevas soluciones digitales y tendencias del mercado financiero.
     ```

2. **Exportación de la Edición 1 del Boletín:**
   * Al finalizar la respuesta de Copilot, selecciona **Exportar a Word** y guarda el archivo con el nombre exacto: `Boletin_Semanal_Edicion1.docx`.

## Resultado esperado
Un documento de Word guardado como `Boletin_Semanal_Edicion1.docx` con la estructura base del boletín corporativo y la primera versión formateada adecuadamente.
